# Icon Gen Lib
This library is used to generate icons for the following platforms and frameworks:
- Android
- iOS
- Web (favicon, manifest and social media)
- Windows (ico)
- macOS (icns)
- Linux (png)

# Usage
See the [documentation](https://github.com/drew-chase/icon_gen/wiki) for usage instructions.
